# Codex execution instructions: reaction hook

Use this file when asked to process a URL or local MP4 with a saved influencer profile. Preserve the user's requirement to use included ChatGPT/Codex image generation. Never silently replace the image step with a billed image API or browser automation.

1. Read README.md and use `python3 hook.py prepare SOURCE --profile PROFILE`. Source and profile must come from the user. If Instagram access fails, report the exact failure and request a local MP4 path. Only use browser cookies if the user explicitly opts in. Do not launch a browser preview.
2. Read the resulting `job.json` and `image-prompt.txt`. Inspect the extracted `first-frame.png` and each identity reference with the image-viewing tool before generation. Review any early-cut or retiming warnings; do not claim that a three-second file guarantees usable continuous motion. Do not invent an influencer identity if the profile is missing.
3. For the automated image path, use the session's native image-generation/editing tool and its applicable imagegen skill. Supply the saved identity references and the extracted frame, keeping their roles explicit. Follow the prompt in `image-prompt.txt`. Generate one starting image, not a batch. If this tool is unavailable, explain the manual ChatGPT fallback; do not use an OpenAI API key as an automatic substitute.
4. Inspect the recreated image for identity, pose, framing, environment, and hands. Copy the selected output into the job through `python3 hook.py attach JOB IMAGE_PATH`. Do not overwrite prior generations. If the user chooses the manual path, give them the image prompt and attachment paths, then wait for the recreated image path before proceeding.
5. Submit only when the user has asked to generate the hook and a fal key is configured locally: `python3 hook.py submit JOB`. This is a paid video-generation request. Keep the Standard endpoint unless the user asks for another model. Never print or ask the user to paste API keys. Do not automatically submit multiple variants.
6. Use `python3 hook.py status JOB --download` to check and retrieve the same request. Persist progress in the job folder. Do not repeat `submit` after timeouts or exceptions. Poll with reasonable backoff and give concise progress updates while waiting. After an interruption, resume the recorded request rather than starting another generation.
7. If the user asks for a check without generation, stop before paid submission and use `python3 hook.py submit JOB --dry-run`. It requires the attached starting image but no fal key or network access. Never submit a paid request during an offline check.
8. Review the downloaded `generated.mp4` before export. A short result remains available for review and is never silently frozen. After approval, use `python3 hook.py finish JOB` (or explicitly choose `--retime` for a short result). The project export includes the three-second hook and the entire reel soundtrack from source time zero as separate assets in project.zip. The MP4 is silent by default; --include-hook-audio optionally adds a short excerpt without replacing the full soundtrack asset. The web Edit step can now join a user-arranged sequence of trimmed clips. This is an explicit local render, separate from generation and Assets exports. Preserve the full soundtrack by default, requiring more footage or an explicit audio-trimming choice if the sequence is too short. Verify the saved `hook.mp4` metadata and inspect selected frames when possible. Describe this accurately as frame inspection; do not claim continuous playback. Report a short or failed generation explicitly. If the user supplies a demo for assembly, treat it as finished content that begins after the three-second hook. Use `python3 hook.py stitch HOOK DEMO --output OUTPUT` to append it locally. Preserve its existing content and audio. During a no-generation check, an assembly made with the reference footage must be labeled as using the original reference, never as a finished influencer result.
9. Return the final video path, selected starting image, source segment timing, retiming mode, request ID if submitted, model, and any unresolved quality issue. If a step is blocked, distinguish prepared assets from an actual finished generation.

Run minimal checks. Do not create unnecessary tests or launch browser previews.
